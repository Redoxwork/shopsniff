How it works

Kane is the product, not the afterthought

ShopSniff doesn't scrape. It gives Kane CLI plain-English missions, Kane carries them out like a shopper, and ShopSniff only trusts values Kane actually observed.

Five missions

Each check is one objective, e.g. "wait 10 seconds, navigate again, store the countdown as timer_after_reload".

Kane shops

kane-cli run "…" --agent --headless drives a real Chrome and stores what it sees with store … as ….

Evidence, not vibes

ShopSniff reads final_state and Kane's step log. No reload in the log means no verdict. Clicks are counted from Kane's own actions.

Score + fix list

An honesty score, a report with TestMu links, and fixes.md for your coding agent. Fix the store and run again until it scores 100.

How do we know ShopSniff is right?

A known-answer test runs on every push. DealDrop's shady mode has all five tricks and ?fixed has none. The self-test passes only if Kane flags 5/5 in the shady store and 0/5 in the honest one.

Kane caught our own bugs. The agent fixed them.

ShopSniff was built with Claude as the coding agent and verified by Kane in GitHub Actions on every push. The agent read Kane's NDJSON output and pushed a fix each time, until the self-test went green.

Run it yourself

Sniff any shop in two commands

You need Node 18+ and a TestMu AI account for Kane CLI.

# install + log in
npm install -g @testmuai/kane-cli
kane-cli login

# sniff a shop
git clone https://github.com/Redoxwork/shopsniff
cd shopsniff
node shopsniff.mjs https://some-shop.example

# prove ShopSniff itself is right
npm run shop &
npm run selftest
# .github/workflows/shopsniff.yml (excerpt)
- run: npm install -g @testmuai/kane-cli
- run: kane-cli login --username "$KANE_USERNAME" \
         --access-key "$KANE_ACCESS_KEY"
- run: node shopsniff.mjs selftest http://localhost:8080/
# reports are committed + published to Pages
# a failed self-test fails the build

For store owners and their coding agents

Every report includes fixes.md. Give it to your agent (see AGENTS.md), fix the store, and run ShopSniff again. The work is done when Kane scores it 100.
