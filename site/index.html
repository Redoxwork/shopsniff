🐽 ShopSniff

Is this shop lying to you?

An AI agent shops like a real person in a real browser, catches the tricks, and gives the store an honesty score with evidence. Every check is run by Kane CLI.

See the reports Shady demo store Honest demo store

The five tricks it sniffs out

⏱️ Fake countdown

Waits, reloads, and checks if “Sale ends in 14:59” starts over.

🔥 Fake scarcity

Reloads three times. If “Only 3 left” keeps changing, it’s made up.

🛒 Sneaky add-on

Adds one item and checks if anything else ended up in the cart.

💸 Hidden fees

Goes all the way to the order review and compares the total with the listed price.

🔒 Cancel maze

Joins the membership, then cancels it, counting every step and any guilt-trip buttons.

How it works

  1. ShopSniff gives Kane CLI five plain-English missions (kane-cli run "…" --agent --headless).
  2. Kane does each one in a real Chrome and stores what it saw (store … as …).
  3. ShopSniff judges the evidence, scores the shop, and writes a report plus fixes.md.
  4. Store owner? Give fixes.md to your coding agent, fix the code, and sniff again until it scores 100.

How do we know ShopSniff is right?

A known-answer test. DealDrop, the demo store, has every trick in its shady version and none in its honest version (?fixed). The self-test runs all five Kane checks on both and passes only if every trick is flagged in the shady store and nothing is flagged in the honest one. See SELFTEST.md.

Built for the Kane CLI Online Hackathon by TestMu AI. DealDrop is a fictional store; ShopSniff never pays or places real orders.
